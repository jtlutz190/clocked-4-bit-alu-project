Demonstrates the ALU's clock circuit and its manual/automatic operating modes. An SPDT switch at the rear of the ALU selects between manual clock control and the automatic clock signal, while a white LED indicates the currently selected mode.

### ALU Control Interface Demo

Demonstrates the manual control interface for the completed ALU. Two pushbuttons on the left breadboard provide system reset and manual clock control. Three SPDT switches beside the input switches control loading of the A input register, B input register, and output register. Three additional SPDT switches on the right side of the ALU select between manual and automatic clock modes and set the 2-bit ALU operation mode.
